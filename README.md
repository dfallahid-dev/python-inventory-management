# Python Inventory Management System

A simple inventory management system written in Python.

## Features

- View all products and their quantities.
- Add new products to the inventory.
- Sell products and update stock quantities.
- Check products with low stock.
- Simple menu-based interface.

## Requirements

- Python 3

## How to Run

1. Download Inventory.py.
2. Open a terminal in the folder containing the file.
3. Run the following command:

`bash
python Inventory.py
